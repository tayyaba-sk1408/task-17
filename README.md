# Day 17 - Password Generator

## Project Description

The Password Generator is a simple and responsive web application that generates random passwords based on user-selected options.

Users can choose the password length and select different character types such as uppercase letters, lowercase letters, numbers, and symbols.

The generated password can also be copied directly to the clipboard.

## Objective

The main objective of this project is to practice:

- HTML form controls
- CSS responsive design
- JavaScript functions
- Checkbox handling
- String manipulation
- Randomization
- DOM manipulation
- Clipboard API

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Adjustable password length
- Uppercase letters option
- Lowercase letters option
- Numbers option
- Symbols option
- Random password generation
- Copy password to clipboard
- Validation when no character type is selected
- Responsive design for mobile and desktop
